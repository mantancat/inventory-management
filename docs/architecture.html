Factory Inventory Management System

A full-stack demo for warehouse operations — inventory, orders, demand forecasting, and spend — wired end to end with mock JSON data standing in for a database.

Vue 3 + Vite :3000 FastAPI :8001 Pydantic v2 Axios In-memory JSON no DB

System Architecture

Three layers, one direction of travel: a browser SPA calls a REST API, which serves data it loaded from disk once, at boot.

Request Lifecycle

What actually happens between clicking a filter and seeing new numbers on screen.

  1. 1

    Filter changes

    FilterBar.vue writes to the shared refs in useFilters.js — selectedPeriod, selectedLocation, selectedCategory, selectedStatus.

  2. 2

    View calls the API client

    A view such as Dashboard.vue reads getCurrentFilters() and calls the matching method on api.js.

  3. 3

    Request is built

    api.js drops any filter still set to 'all' and issues an axios.get to http://localhost:8001/api/... with the rest as query params.

  4. 4

    FastAPI resolves the route

    main.py's apply_filters() and filter_by_month() narrow the in-memory lists by warehouse, category, status, and month or quarter.

  5. 5

    Response is validated

    The matching records are checked against the endpoint's response_model (e.g. List[InventoryItem]) before FastAPI serializes them to JSON.

  6. 6

    Vue re-renders

    The payload lands in a ref; computed properties derive totals, chart series, and table rows from it.

NOTES

  • Data is in-memory only — every restart reloads server/data/*.json from disk, so nothing written back persists.
  • CORS is wide open (allow_origins="*") and there's no auth layer; server/CLAUDE.md flags both as demo-only, not production settings.
  • client/.npmrc pins the public npm registry and package-lock.json is gitignored — guardrails against a private registry leaking into this public repo.
  • api.js calls /api/tasks and /api/purchase-orders for the Tasks panel and the backlog "create PO" flow, but neither route exists in main.py — those requests fail quietly and the UI falls back to the mock task list in useAuth.js.
